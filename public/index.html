🧪 Diagnóstico de Criação de Veículo

Teste real de inserção na API /api/devices do seu Traccar.

Por que os veículos podem não ser criados?
  • Conta Traccar com permissão deviceReadonly.
  • Limite de aparelhos da conta atingido (deviceLimit).
  • URL Traccar apontando para proxy com redirecionamento bloqueado.

💡 Guia Rápido para Servidor Remoto:

  • Permissão Negada (403): Certifique-se de que a conta não possui a trava de somente leitura no Traccar.
  • Porta customizada: Em VPS (AWS, DigitalOcean, Hetzner), libere a porta TCP no Security Group/UFW.
  • Sincronização: Clique em Salvar Configurações após alterar os campos para atualizar o motor de simulação.
